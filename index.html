실시간 물리식

연속식: A₁v₁ = A₂v₂ → v₂ = 0 m/s
베르누이: ΔP ≈ ½ρ(v₂²−v₁²) → ΔP = 0 kPa
오일 이동: Qₒ ∝ (ΔP × 니들 개방) → Qₒ = 0 방울/s

유량을 올리면 v₂가 증가하고, 그 결과 정압이 더 낮아져 오일 흡입 가능성이 커집니다. 실제 장치에서는 점도·온도·치수에 따라 달라집니다.
